## Features

- A high-impact hero with a clear "book a free trial" call to action
- Benefits, about, and community sections that build trust
- **Classes for every level**, plus a **weekly timetable**
- **Booking** for a week or month of training
- A one-to-one **personal training** section
- Results, testimonials, and contact sections
- A fully responsive, mobile-first layout

## Tech stack

A single, self-contained `index.html` file of hand-written HTML, CSS, and
vanilla JavaScript. It has no frameworks and no build step.

## Run locally

```bash
git clone https://github.com/dean1234533/Apex-boxing-club-Premium-Website-Mockup.git
cd Apex-boxing-club-Premium-Website-Mockup
open index.html   # or double-click it
```
